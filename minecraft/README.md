# Minecraft — CC:Tweaked Lua Concepts

> **The same ideas as Python, but running inside Minecraft as a robot.**

This section is the companion to the **Friday Minecraft Shorts** on [@CognitoCoding01](https://www.youtube.com/@CognitoCoding01).

Each folder = one concept. One Short. One plain explanation. A Lua script that runs in-game as-is.

---

## Why CC:Tweaked?

CC:Tweaked is a Minecraft mod that adds programmable turtle robots. You write Lua to make them move, dig, place blocks, and print messages. Real code, real robot, and the machine it builds stays in your world.

The concepts here — variables, loops, functions, conditions — are the same ideas as Python. The syntax looks different but the thinking is identical.
