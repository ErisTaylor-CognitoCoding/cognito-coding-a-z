# Walk and Turn — forward(), turnLeft(), turnRight()

> **The three commands that move a turtle around the world.**

---

## The analogy

A turtle starts facing one direction. `turtle.forward()` moves it one block forward. `turtle.turnLeft()` and `turtle.turnRight()` rotate it 90° without moving. Chain these together to navigate.

---

## The code

```lua
turtle.forward()
turtle.forward()
turtle.turnLeft()
turtle.forward()
turtle.turnRight()
turtle.forward()
print("Done walking.")
```

---

## Why it matters

These three commands are the building blocks for every path a turtle takes. No coordinates — just relative movement. Think of it as giving turn-by-turn directions.
